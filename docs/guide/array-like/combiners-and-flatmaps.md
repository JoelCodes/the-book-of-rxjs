Where the Array analogy stretches: mapping each value to an **inner Observable** and flattening the results back into one stream — `mergeMap`, `concatMap`, `switchMap`, `exhaustMap` — plus the combiner functions that join several streams. This page is the bridge from array-like thinking into [Process Management](/guide/process-management/).
