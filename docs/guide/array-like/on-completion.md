# Firing on Completion

::: info Draft in progress
This page is a stub. Related archived draft: [Array and Iterable-like Operators](/archived/guide/array-like-operators).
:::

Operators that have to wait for the source to complete before they can emit — they need to see every value first. `reduce`, `toArray`, `count`, `max`, `min`, `last`, `every`, `isEmpty`, `defaultIfEmpty`. These are exactly the Array methods that return a single answer.
