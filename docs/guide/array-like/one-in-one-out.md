# One In, One Out

::: info Draft in progress
This page is a stub. Related archived draft: [Array and Iterable-like Operators](/archived/guide/array-like-operators).
:::

Operators where each source value produces exactly one output value — the stream's shape stays the same, only the values change. `map`, `scan` (a running `reduce` that emits each step), `pairwise`, and friends.
